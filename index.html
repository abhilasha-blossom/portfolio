Projects

StreetBite

StreetBite is a web platform that helps users discover nearby street food vendors using real-time location. Vendors can register their stalls, upload menus and photos, update availability, and manage their profiles, ratings and reviews, and navigate through an interactive map. Built with Next.js, Spring Boot, Firebase Firestore, and Map APIs, StreetBite helps small food stalls build a digital presence and helps users explore affordable, authentic street food.

Next.js · Spring Boot · Firebase · Map APIs

Koikana (KoiKana)

A React-based Japanese learning app blending Zen minimalism with smart repetition. Features a Zen Garden Progress Tracker, Canvas-based "Sand Garden" writing practice, and dojo-style quizzes. Designed to be an experience-driven language dojo, not just a memorization tool.

React (Vite) · Tailwind · Supabase · HTML5 Canvas
